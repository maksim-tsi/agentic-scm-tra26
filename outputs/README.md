# Outputs

Runtime artifacts produced by evaluation runs:

- execution logs
- JSON reports
- YAAM memory dumps
- traces/exports (e.g., Arize Phoenix)

This directory is gitignored by default (except this README).

## Usage Notes

- Treat everything in this directory as generated runtime data.
- Artifacts may include prompts, traces, or memory-derived content; review before sharing.
- Cleanup is manual unless a dedicated retention script is introduced.
